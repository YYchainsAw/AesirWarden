# 本机服务与通信边界

> 状态：源码核对 + 部署待验收 · 2026-09-29

项目目标为单机战斗，但 UE 与本机 Python 服务通过 HTTP 通信，因此不能写成“完全没有网络接口”。

| 端点 | 用途 | 对游戏的要求 |
| --- | --- | --- |
| `127.0.0.1:8012/v1/boss/policy/decide` | 冻结 Boss 策略返回高层 Action | UE 校验协议、请求/序列、Schema、模型 ID、Action ID；失败时本地 BT 回退 |
| `127.0.0.1:8011` 下的命令/战术端点 | 同伴文本/语音目标链路 | 非当前 Boss 战的关键依赖；UE 保留执行权威 |

Boss Client 默认决策间隔 0.25 秒、请求超时 0.20 秒、连续失败阈值 3，见 [PolicyClient.h](../../../Source/AesirWarden/Public/AI/Boss/AesirBossPolicyClientComponent.h)。这些是当前可配置默认值，不是性能验收结果。打包测试须记录服务启动方式、模型文件、端口占用、超时/断开、错误协议及模型版本；若分发给其他机器，应明确是否捆绑 Python 服务及依赖。当前没有多人联机或远程服务器架构。
