# 符文能力管线

> 状态：目标设计；当前只有 GAS 基础、RunePower/CooldownHaste 属性和部分能力资产 · 2026-09-29

目标管线：

1. 存档持有符文 ID；战斗入口选择两枚已拥有符文。
2. 装备定义把符文映射为 GameplayAbility 与 UI 数据；ASC 授予或移除相应能力。玩家固有 Guard 保持不变。
3. 输入或战术指令提出施放；UE 校验装备、目标、状态与权威，GAS 校验冷却/标签/成本。
4. 能力控制 Montage/Ability Task、投射物或命中检测、Gameplay Effect 与 Gameplay Cue；伤害和受击状态由 UE 结算。
5. UI 依据 ASC 状态展示冷却与失败反馈；遥测记录激活、拒绝、命中和中断。

当前工程未核到通用符文定义、两槽装备、投射物/元素判定或完整法术生成系统。本页不把它们写成已存在的代码路径。落地第一条符文能力时先冻结 ID→GameplayTag→GA 的映射、目标规则、冷却与效果，再补实例时序图和测试。
