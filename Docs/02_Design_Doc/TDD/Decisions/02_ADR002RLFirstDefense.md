# ADR-002：答辩优先单 Boss RL 对照

- 状态：Partially Superseded（开发顺序由 2026-10-07 路线调整）
- 记录日期：2026-09-29

## 背景

项目同时包含战斗、同伴命令、动画与进度系统。学期答辩需要可稳定完成的研究主线，而 RL 贡献不能停留在算法名称或精选片段。

## 原决定（2026-09-29）

先完成单 Boss 的 BT–PPO 共享执行、训练、独立评估、回退和可玩闭环；文本/语音同伴真实 GAS 指令执行、多敌 MARL 和大量成长内容推迟到后续阶段。菜单/检查点在 P0 稳定后完善。

## 后果

单 Boss 对照保留为研究主线，实验契约、原始数据、运行时性能和失败案例仍需记录。公平对照所需的共享执行边界继续按 [ADR-001](01_ADR001SharedBossExecutor.md)执行。

## 后续调整（2026-10-07）

已确认的[开发路线](../../../05_Development_Guide/06_DevelopmentRoadmap.md)改为先完成 **M1 BT Boss 全流程**，再以 M2 RL Boss 为重点推进；M4 玩家数值、技能和手感，以及 M5 AI 队友聊天与战斗接入，也属于当前整体交付目标，可按依赖并行准备。

因此，原决定中“菜单在 RL 实验之后”“同伴与玩家成长统一延期”的推进口径已被上述路线调整；具体任务顺序由开发路线维护。[目标与范围](../../../01_Project_Overview/02_GoalsAndScope.md)保存当前边界，持久检查点与具体成长方案仍待确定。本文保留旧决定及调整缘由，不表示这些功能已经完成。
