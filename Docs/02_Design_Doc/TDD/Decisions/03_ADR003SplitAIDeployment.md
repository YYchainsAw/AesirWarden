# ADR-003：Boss本地推理与远程NPC服务

- 状态：Accepted（2026-10-21用户采纳的目标架构；实现、协议协作与运行验收未完成）
- 记录日期：2026-10-21

## 背景

Boss按0.25秒周期决策、HTTP超时0.20秒，公网往返会占用战斗预算。NPC对话和语言理解适合异步服务，但原文档只覆盖本机单玩家、JSON文件及无入站认证的联调。多个独立单机客户端共享NPC服务时，同一角色ID不能继续作为唯一存储或限流作用域。

## 决定

Boss冻结策略、BT及队友实时执行留在玩家本机；NPC文本理解、对话、检索和高层建议部署远程服务，服务转接外部LLM/ASR。长期记忆和关系在服务端按已认证玩家及存档隔离，客户端缓存和真实事实队列按版本、去重与重置屏障同步。初始Boss模型随游戏交付，后续可通过服务端版本清单更新。

UE仍是单机世界权威，不引入多人联机战斗。首期本地Boss复用独立推理进程，ONNX/NNE是后续可选实现；训练与在线服务分开调度。职责、模型交付、离线行为及UE验收只在[部署说明](../06_Deployment.md)完整维护；2026-10-21两仓按其中`placement-v1`的15项能力对照。Python仓库的`docs/planning/ai-capability-placement.md`和六步方案维护服务侧分工与开发顺序，具体接口变更仍需同步契约。

## 后果与取代范围

取代技术架构、服务约定及后端SDD中“正式部署只在本机”“公网服务及玩家隔离均范围外”的限定；本机8011/8012继续作为开发现状。既有Boss动作契约、共享GAS、故障回退及研究隔离规则不变。服务端需实现认证、事务存储、隔离、同步和资源限制，UE需实现配置、进程交付、缓存与恢复；API字段变更另按版本兼容规则落地。
