# 存档与重试设计

> 状态：目标设计；当前工程未发现 USaveGame 或完整持久存档实现 · 2026-09-30

## 答辩版重试

[第一关流程](../GDD/GameFlow.md)规定：玩家失败后重试从**关卡开头**重新游玩，不从 Boss 场地入口复活，也不读取 Boss 检查点。首版可通过重新初始化第一关恢复玩家初始位置、生命、守防、能力、冷却、敌人、机关和关卡事件；完整持久存档不是此流程的前置条件。

一次关卡启动需要区分两个临时入口模式：冷启动/返回菜单时呈现营火菜单；失败后重试时跳过营火菜单及开场运镜，直接从营火初始可玩位置开始。实验模式与必要的实验配置可跨重载保留，但上一局的伤害、结果、Widget、委托、Policy Client 请求/失败计数及 Boss Episode 不得残留。再次抵达 Boss 场地才创建新的 Episode。

## 后续持久数据

若以后增加“继续游戏”，应另行设计版本化存档及关卡检查点；它不改变当前重试规则，除非经过新的设计决定。进度数据可包含经验、下次技能点阈值、未用技能点、五项属性等级（每项 1–9）、已解锁能力、拥有符文、两枚装备符文和武器定义 ID。瞬时 Health、GuardPressure、冷却剩余时间不能直接替代这些进度字段；加载时先验证版本与 ID，再转换为运行时 GAS 初值。

## 验证

至少测试冷启动营火菜单、开始游戏、死亡后连续重试两次、每次从关卡开头重新进入、返回主菜单、新 Episode ID、重复死亡事件不二次结算，以及旧 UI/委托/策略请求清理。当前 [GameMode](../../../Source/AesirWarden/Private/Framework/AesirCombatPrototypeGameMode.cpp)只在 BeginPlay 收集当时存在的敌人，若改为战斗中生成须重做登记与胜利判定。
