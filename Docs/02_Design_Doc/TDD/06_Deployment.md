> 2026-10-21用户采纳的目标方案。当前代码仍以本机Python HTTP联调为主；远程鉴权、玩家隔离、同步、外部ASR适配和模型自动分发尚未实现或验收。本页维护UE部署和离线行为，不复制API字段表。

同日采纳的EVO-20261021在[NPC交互与服务演进](07_NPCInteractionEvolution.md)维护五方面20项机制、用例扩展与实施依赖，继续使用本页AI-DEP编号。本页负责位置与离线边界，演进页负责轮次/语音/事件/记忆/服务协作；VAD、TTS及回复打断为后置实现，不把AI-DEP-12本地录音/播放位置声明当成整条语音链已完成。

## Boss本地交付

首期复用本机HTTP契约，随Windows游戏提供独立Boss推理程序、运行依赖、冻结模型和交付材料；玩家无需自行安装Python。程序只监听回环地址。游戏负责隐藏启动、就绪检查、退出回收、崩溃识别与多实例端口冲突处理，启动失败转本地BT，不阻塞菜单。当前尚无这些打包与进程管理实现。

后续可评估导出ONNX接UE NNE；这不是当前已有能力，也不成为首期交付前置。迁移时逐项验证26维输入、9动作顺序、确定性选择和动作mask；全部动作不可用时保持合法无动作，不把训练模拟器的补偿逻辑当游戏规则。推理运行方式改变后仍使用同一GAS执行边界。

初始模型随包分发，服务器提供版本清单和可选更新。清单包含模型版本、SHA-256、协议/Schema、输入维度、动作映射、兼容游戏构建及所需推理运行时版本，产物来源见[训练记录](../../08_RL_Research/02_TrainingHistory.md)。客户端验证可信发布来源和清单签名，再核对文件哈希与兼容性；SHA-256只证明完整性。候选下载到临时位置，校验后在菜单或新遭遇前原子切换，失败保留上一已验证版本；不在战斗中修改权重。正式实验固定模型与配置，自动更新关闭。当前没有模型发布端点、签名校验或下载器，不能把Git克隆当交付。

## NPC连接与本地缓存

正式地址使用可配置的远程HTTPS入口，开发仍可选`127.0.0.1:8011`；当前两个Subsystem的硬编码需要实现配置入口。开发地址不能在正式包中静默替代远程地址。LLM/ASR供应商密钥仅存服务器；UE使用可撤销、可过期的玩家会话凭据，打包的固定共享密钥不提供玩家身份。

当前`party.player`和`companion.alice`等是世界或角色标识，不是已认证玩家身份。服务端从认证主体验证存档归属，再绑定游戏、角色、会话及遭遇；不能仅由请求自报ID取得其他玩家数据。旧接口没有完整作用域保护时仅供开发，不直接开放公网。

UE保存本玩家/存档的版本化只读缓存和待同步的真实事实/回执，不允许用本地关系分数覆盖服务权威值。跨玩家切换先清理会话和缓存引用；重试换游玩/遭遇身份，分支读档按存档世代隔离。缓存范围、服务端事务、幂等确认、冲突和记忆重置屏障是AI-DEP-10的目标；具体同步API和字段尚待Python契约、存储实现与UE共同对齐，现有接口不能仅靠追加字段视为已支持。

## 断网、超时与恢复

| 情况 | UE行为 | 恢复边界 |
| --- | --- | --- |
| 启动时NPC服务不可达 | Boss本地推理/BT和基础队友行为继续，菜单及开始不等待网络 | 云端聊天和新增语言指令提示不可用，保留本地已实现的直接操作 |
| 战斗中断网或NPC超时 | 维持本地基础AI；已接受且当前遭遇内仍有效的条件指令可继续，执行时照常校验 | 不补发过期心跳、旧建议、历史聊天或新的战斗动作 |
| Boss本地程序或模型失败 | 按[RL契约](../../08_RL_Research/01_BossRLContract.md)回退BT | 本场不自动恢复PPO，不把NPC重连当重开遭遇 |
| 外部ASR不可用、空转写或含糊 | 给可恢复原因并允许文本输入，不执行猜测指令 | 不自动重复上传历史音频；本地Whisper不是未声明的生产兜底 |
| 身份失效或切换玩家/存档 | 暂停该作用域的云端读写，隔离缓存和待同步项，游戏基础流程继续 | 重新认证并确认归属后再同步，不降级成匿名共享角色 |
| 网络恢复 | 有退避和上限地探测，认证有效后取新版本/新快照，确认去重后上传真实待同步事实 | 重连不恢复过期命令，不清空或重建当前世界；队列未确认前不宣称云端已保存 |
| 终局、重试、返回或退出 | 取消请求，使旧游玩/遭遇回调失效，持久保存可重试的事实队列 | 退出不等待云端；旧事实可归档到原身份，不触发当前世界动作 |

网络恢复后，以服务端权威快照、版本和重置屏障收敛；缓存删除/重置后的旧队列不得让记忆复活。离线队列有可配置容量和保留期限，达到上限时显示未同步状态并按记录策略处理，不无限增长或静默标成功。不得把所有离线对话自动补成已发生的云端对话。
