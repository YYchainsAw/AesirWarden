# 物品、掉落与成长

> 状态：范围约束与目标概念 · 2026-09-29；当前不列为答辩 P0。

当前 C++ 未发现可核对的通用 Inventory、Loot、Experience、SkillPoint 或 SaveGame 实现。本页因此不规定虚构的掉率、词缀、品质或商店经济。

答辩版本如时间不足，只需预设战斗状态与必要能力，不强制掉落。后续成长系统的最小持久数据为经验、下一个技能点阈值、未用技能点、五项 1–9 级属性、已解锁能力、拥有符文、两个装备槽和当前武器定义；详见[存档设计](../TDD/SaveSystem.md)。

若引入战利品，先定义其对核心战斗循环的作用，再补资产表、掉落来源、叠加/持有上限、存取规则与可测试的掉落概率。装备状态使用互斥标签或定义资产，不以一个布尔值表示是否持武器。
