# 编辑器内 C++ 迭代注意事项

> 状态：项目工作约定 · 2026-09-29

在编辑器开着时更改普通函数实现，可先尝试当前 UE 提供的快速编译流程，但仍需在最终验证前重启编辑器并做完整构建。涉及反射声明、组件默认子对象、Ability/AttributeSet 类型、序列化字段、Blueprint 父类或公共枚举时，使用关闭编辑器后的完整编译和资产重新打开核查。

如果出现蓝图变量丢失、组件重复、默认值异常或 ABI/反射错误，先保存日志和受影响资产清单，再回到已知良好源码/资产版本重建；不要在异常状态下继续保存大量 Blueprint。将复现和处理结果写入[KnownIssues](../06_Test_Doc/KnownIssues.md)。
