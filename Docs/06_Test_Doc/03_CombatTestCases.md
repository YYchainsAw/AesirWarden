# 战斗测试用例

> 状态：可执行用例草案；2026-09-29 未运行本轮测试。

| ID | 前置条件与操作 | 期望结果 |
| --- | --- | --- |
| C-01 | 玩家进入 Boss 关卡，移动、转镜头、锁定/解除锁定 | 目标切换、镜头和移动方向稳定；失效目标被清除 |
| C-02 | 从待机、跑动、侧移分别轻击/重击 | Montage 进入/恢复自然，命中只在有效窗口结算一次 |
| C-03 | 攻击中或受击硬直时请求闪避 | 仅在规则允许的窗口执行；无双重伤害/无敌残留 |
| C-04 | 对普通攻击持续守防 | GuardPressure 增加，达到上限后破防与限时硬直 |
| C-05 | 对重攻击分别普通守防与完美防御 | 普通防御破防；完美防御成功时开放反击窗口 |
| C-06 | 对不可防御攻击普通/完美防御、闪避 | 两类防御无效；闪避与脱离范围可规避 |
| C-07 | Boss/玩家生命归零与连续死亡事件 | 仅一次结算；结果 UI 状态一致 |
| C-08 | 失败结果页连续重试至少两轮，并再次走到 Boss 场地 | 每次从第一关营火起点开始；再次开战产生新 Boss Episode；旧生命/冷却/委托/UI/回退状态不残留 |

每项记录攻击资产、输入时间、目标状态、GAS 激活/拒绝、Health/GuardPressure 前后值、视频帧和构建。未固定的伤害公式与时间窗按实际配置记录，不在用例中假设数值。
