# 文档与配套文件命名

> 2026-10-08：适用于 AesirWarden 的 `Docs/`。本次只整理命名与引用，不改变业务或验收基线。

## 文件名规则

- 正式文档、维护脚本、JSON 清单和导出图采用 `NN_PascalCase.ext`，例如 `01_GameFlow.md`、`12_CurrentIssues.json`、`02_GameUseCases.puml`。
- `NN` 是同一目录中的两位阅读/处理顺序，从 `01_` 开始；目录分别编号，不在整个仓库跨目录连续编号。序号不是里程碑、任务编号或完成状态。
- 每个目录的入口保留 `README.md`，便于 GitHub 自动展示；用户已删除的维护说明、变更记录和清理映射不重新创建。
- UML 图和原脚本同目录、同名，仅扩展名不同，例如 `02_GameUseCases.puml` / `02_GameUseCases.png`。文件改名不修改图内类名、参与者、模型 ID 或业务关系。
- ADR 的稳定标识保留在文件名和正文中，例如 `01_ADR001SharedBossExecutor.md`；已删除文件的编号留空，不重新编号填补空缺。
- 历史任务清单使用 `History`，当前正式路线不再保留误导性的 `Draft` 后缀；确实仍待审核或只是发布中间产物的文件继续保留 `Draft`。
- JSON 清单使用数字前缀，例如 `12_CurrentIssues.json`。按用户要求，不保存或生成课程 ZIP；已删除的 SRS 目录及其脚本不重新创建。

## 保留原名的范围

- `README.md` 是目录入口。
- AI 仓库的图源保留原有 `11-`、`12-`、`13-` 编号和短横线文件名，按照该仓库现存目录维护；UE 不另存 NPC 素材副本。
- 固定 Git 提交 URL 中的文件路径属于当时证据，保留原名。当前本地链接和指向动态分支的引用则更新为新路径。
- 跨仓引用保留 AI 仓库名称和权威文件名；本规范不改另一仓库的目录安排。

## 改名时同步维护

1. 更新目录 README、正文链接、图片、图源、普通路径引用及 Issue 模板入口。
2. 修改图源后同步导出同名预览，并核对正文链接；保持用户调整的目录位置。
3. 核对改名前后路径，保持固定提交的历史证据 URL；用户已经删除的文件及目录不恢复。
4. 删除草稿或历史文件前核对替代资料和引用，按用户授权范围执行。本次 ABC 三组的 10 个文件已全部删除，不生成课程 ZIP。
